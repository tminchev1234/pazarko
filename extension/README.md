# Pazarko — реалната цена (браузър разширение)

„Keepa за България." Показва **нашата** ценова история и издава **фалшивите намаления**
директно върху страницата на продукта в eMAG, Ozone, Технополис, Техномаркет, Zora, Ardes.

Когато отвориш продукт, който следим, долу вдясно изскача малка карта:
- 🏆 „Най-ниска цена, откакто следим" / ✅ „Реална отстъпка"
- ⚠️ „Фиктивно „намаление“ — това е обичайната цена"
- 🔴 „Близо до най-високата — изчакай"
- 📉 „Преди ~месец: X лв · сега Y лв" + мини графика на цената

Всичко се смята от нашата `price_history` (не от обявената от магазина „стара цена").

## Как да го заредиш (за тест, без Chrome Web Store)

1. Chrome/Edge → отвори `chrome://extensions`
2. Горе вдясно включи **Developer mode**
3. Бутон **Load unpacked** → избери папката `extension/`
4. Отвори продукт в някой от магазините — картата изскача, ако имаме история за него

## Как работи (архитектура)
- `content.js` — на страницата на магазина праща текущия URL към service worker-а; рендерира картата в Shadow DOM (изолиран от CSS-а на магазина).
- `background.js` — тегли `GET /api/alex/price-history?url=...` от Pazarko API (`host_permissions` → без CORS проблеми).
- Backend-ът match-ва URL-а хитро (толерира query-параметри, trailing slash и променливия slug на eMAG чрез `/pd/КОД/`).

## Публикуване (по-късно)
За Chrome Web Store трябва: dev акаунт ($5 еднократно), икони (16/48/128px), screenshots и ревю (~няколко дни). Тази версия е за локален тест и демо.

## Покритие
Показва данни само за продукти, които вече следим. Колкото повече расте `price_history`
(дневен скрейп), толкова повече продукти ще имат карта.
